# 使用说明（图形界面版）

## 一、开始使用

1. **双击 `zhihu2md-gui-*.exe`**（单文件，不需要安装 Python）。
2. 把知乎编号或链接粘进「要保存的内容」框，可以一次粘多条，也可以直接把收藏夹页面全选复制、整段粘进来。
3. 点 **「开始保存」**，下方日志会实时显示进度。
4. 保存结果在「输出目录」里：一篇 `.md` + 一个 `assets\` 图片目录。

> 建议把「输出目录」改到你的 Obsidian 库里（点「浏览…」选一个文件子文件夹），
> 之后导出的笔记会直接出现在 Obsidian 侧边栏。
> 注意：`.md` 和它的 `assets\` 目录要放在一起，图片是按相对路径找的 —— 整个目录一起拷贝即可。

## 二、第一次必须配 Cookie

知乎对未登录请求一律返回 403，所以要先准备一份 Cookie。两种方法任选：

### 方法 A：只抄一个值（最快）

1. 浏览器里**登录**知乎，按 `F12` 打开开发者工具；
2. 切到 **应用程序（Application）** 标签 → 左侧 `Cookie → https://www.zhihu.com`；
3. 在表格里找到 `z_c0` 这一行，**双击「值」单元格** → `Ctrl+A`、`Ctrl+C`；
4. 回到程序点 **「粘贴识别」**（只粘值也行，会自动补成 `z_c0=…`）→ 点 **「保存 Cookie」**。

### 方法 B：整段请求头 / cURL

1. `F12` → **网络（Network）** → `F5` 刷新；
2. 点列表里一条真正的 `www.zhihu.com/api/...` 请求（**不要点 `blob:` 开头的**，那不是网络请求，没有 Cookie）；
3. 右键该请求 → **复制 → 复制请求标头**（或 `复制为 cURL`）；
4. 程序里点 **「粘贴识别」** → **「保存 Cookie」**。

### 怎么确认配好了

日志里出现这样的行就说明成功：

```
Cookie 检查通过 (共 812 字符).
Cookie 字段: BEC, d_c0, q_c1, z_c0, _xsrf
```

只要字段里有 `z_c0` 就对了。如果提示「缺少 z_c0」，说明复制错了请求或者没登录。

> Cookie 只保存在程序旁边的 `cookie.txt` 里，**只在本机使用**，不会上传到任何地方。
> 它一般几个月才过期，过期后重新取一次即可。

## 三、界面上的选项

| 选项 | 说明 |
| --- | --- |
| 输出目录 | 保存位置，建议设在 Obsidian 库里 |
| Cookie | 支持直接粘贴 cURL / 请求头 / 裸字符串，点「粘贴识别」自动提取并体检 |
| 代理 | 需要走代理时填写，例如 `http://127.0.0.1:7890` |
| 命名方式 | 「标题优先」用文章标题当文件名；「作者优先」变成 `作者 - 标题` |
| 下载图片到本地 | 默认开启；关掉则正文保留远程图片链接 |
| 跳过已保存的内容 | 定期增量备份时勾上，同编号不会重复处理 |

## 四、常见问题

**双击后 Windows 提示「已保护你的电脑」**
程序没有代码签名，属于正常现象：点 **更多信息 → 仍要运行**。

**双击后要等 1~2 秒才有界面**
单文件程序每次启动会先把运行时解包到临时目录，正常现象。

**杀毒软件报可疑**
PyInstaller 打包的程序常被误报。可以加入信任列表，或改用源码运行。

**日志报 403 / 需要登录**
Cookie 无效或过期，重新按第二节取一次；若仍 403，用浏览器打开目标页面完成一次安全验证再试。

**某些图片没下载下来**
个别图片有防盗链，程序会带 Referer 重试；仍然失败的会退化成远程链接，正文不会缺位置。

**付费内容 / 盐选专栏**
只能保存登录后能正常看到的部分，程序不会绕过付费墙。

**程序目录里的文件都是什么**
`cookie.txt` 登录态（别发给别人）、`gui-settings.json` 界面设置（不含 Cookie）、
`gui-log.txt` 最近一次运行日志（出问题时可提供给作者）、`zhihu-archive\` 输出目录。

## 五、自检（可选）

```powershell
.\zhihu2md-gui.exe --self-test    # 验证 抓取 → 转换 → 图片 → 落盘 全链路（不联网）
.\zhihu2md-gui.exe --smoke-ui     # 验证界面组件是否完好（窗口不会弹出）
```

结果写在同目录 `selftest-result.txt` / `smoke-ui-result.txt`，退出码 0 即通过。
