# 使用说明
## 一、开始使用

1. **双击 `exe`**.
2. 把知乎编号或链接粘进「要保存的内容」框, 可以一次粘多条. 选择保存路径.
3. 点 **「开始保存」**, 下方日志会实时显示进度.
4. 保存结果在「输出目录」里: 一篇 `.md` + 一个 `assets\` 图片目录.

> 建议把「输出目录」改到你的 Obsidian 库里 (点「浏览」选一个文件子文件夹);
> 之后导出的笔记会直接出现在 Obsidian 侧边栏.
> 注意: `.md` 和它的 `assets\` 目录要放在一起, 图片是按相对路径找的, that's to say 整个目录一起 copy 即可.
> **付费内容 / 盐选专栏**: 程序不会绕过付费墙, 所以当然就不能保存这些内容辣.

## 二、第一次必须配 Cookie
知乎对未登录请求一律返回 403, 所以要先准备一份 Cookie. 您可以选择:

1. 浏览器里**登录**知乎, 按 `F12` 打开开发者工具, 随后按 `F5` 刷新;
2. 选择列表里一条真正的 `www.zhihu.com/api/...` 请求, 右键该请求 → **复制为 cURL (cmd)**;
3. 程序里点 **「粘贴识别」** → **「保存 Cookie」**.

> Cookie 只保存在程序旁边的 `cookie.txt` 里, **只在本机使用**.
> 它一般几个月才过期(吧?), 过期后重新取一次即可.

## 三、界面上的选项

| 选项 | 说明 |
| --- | --- |
| 输出目录 | 保存位置, 建议设在 Obsidian 库里 |
| Cookie | 支持直接粘贴 cURL / 请求头 / 裸字符串, 点「粘贴识别」自动提取并自检 |
| 代理 | 需要走代理时填写, 例如 `http://127.0.0.1:7890` |
| 命名方式 | 「标题优先」用文章标题当文件名; 「作者优先」变成 `作者 - 标题` |
| 下载图片到本地 | 默认开启; 关掉则正文保留远程图片链接 |
| 跳过已保存的内容 | 定期增量备份时勾上, 同编号不会重复处理 |
